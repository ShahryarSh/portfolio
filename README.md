# Portfolio Website Responsive Design & Viewport Documentation

## Breakdown of different viewports

## First is full sized desktop/laptop viewport under the name of full.css
## The professional web design standard for laptops and desktop monitors is 960 pixels.
## 960 pixels fits widescreen displays cleanly and is easily divisible

## Second is the tablet viewport under tablet.css
## The min width 481px and mad width 960px targets mid-sized tablet displays such as ipads

## Third is the smartphone / mobile viewport under phone.css
## max width 480 px due to narrow screens. no float forces all content and sections into a single vertical column.
## The navigation links become full diwth stacked buttons, easy for tapping and removing horizontal scrolling
